# 忙里偷题：单个题库的导出与导入

日期：2026-11-26
状态：已实现（2026-11-26 验收：后端 90 项、学习端组件 59 项、管理端 5 项、E2E 4 项全部通过，两个前端生产构建成功；真实浏览器完成题库导出与导入验收）
范围：管理端题库页按题库导出、导入题目

## 1. 背景

现有的导出只有「数据」页的账号全量 JSON（含学习进度），导入只有 Anki 页的 `.apkg` 与纯文本。想单独备份、分享或迁移某一个题库时，没有可用入口：题库页只有新建、编辑、删除，「导出回 Anki」是未实现的占位。

## 2. 目标与边界

### 包含

- 从管理端题库页导出单个题库：JSON 或 CSV。
- 往指定题库导入题目：JSON、CSV、TSV；给出导入报告。
- 不含学习进度：题库导出只搬运题目内容，不导出记忆状态、复习日志和计划（那是「数据」页全量导出的职责）。

### 不包含

- 学习端入口（普通用户的数据主权入口另行处理）。
- `.apkg` 导出、Excel 文件解析。
- 导入时自动新建题库；需要新题库时先在题库页新建。

## 3. 接口

两个接口都校验题库归属，不属于当前用户时返回 404。

### 导出

`GET /api/v1/questions/banks/{bank_id}/export?format=json|csv`（默认 `json`），以附件形式返回，文件名 `题库-<名称>-<日期>.<扩展名>`。

JSON 结构：

```json
{
  "format": "moneytotip-bank",
  "version": 1,
  "bank": { "name": "Python", "description": "……" },
  "exported_at": "2026-11-26T06:00:00Z",
  "questions": [
    {
      "stem": "……", "answer": "……", "qtype": "choice", "options": ["甲", "乙"],
      "explanation": "……", "source": "……", "tags": ["Python"], "difficulty": 2,
      "status": "active", "category": "Python::数据与类型"
    }
  ]
}
```

`category` 是 `::` 分隔的分类路径，未分类为 `null`。

CSV 固定十列：`题面, 答案, 题型, 选项, 讲解, 来源, 标签, 难度, 分类, 状态`。题型和状态用中文文案（选择 / 填空 / 判断 / 问答 / 场景设计；待确认 / 复习中 / 需修正 / 已暂停），选项一格一行，标签空格分隔，文件带 BOM 方便表格软件直接打开。

### 导入

`POST /api/v1/questions/banks/{bank_id}/import`， multipart 上传 `file`，大小上限 64MB。

- 按扩展名识别格式：`.json`、`.csv`（逗号）、`.tsv` / `.txt`（制表符）。
- JSON 接受两种：题库导出文件（`moneytotip-bank`），或题目数组（与命令行 `question-import` 同一字段）。
- 表格文件必须有表头，列名中英文都认（如 `题面` / `stem` / `front`），至少要有题面和答案两列。
- 每行入目标题库；`分类` 按 `::` 路径查找或创建分类。
- 去重范围是目标题库：题面加答案与库内已有题或文件内前面的行相同即跳过。
- 状态：行里给了合法状态就沿用，否则进预览区（待确认）。声明「复习中」但没通过入队校验的题降为待确认并在报告里说明。
- 来源留空时填 `导入：<文件名>`，保证每道题可溯源。
- 合法行一次事务提交；文件无法解析（格式不对、缺表头、没有数据行）时整份拒绝，不写入任何题目。

报告：

```json
{
  "bank": "Python", "created": 12, "duplicates": 3,
  "by_status": { "pending": 5, "active": 7 },
  "invalid": [{ "line": 7, "reason": "缺少题面" }],
  "needs_review": [{ "line": 9, "stem": "……", "reasons": ["选择题答案必须是有效选项之一"] }],
  "truncated": false
}
```

`invalid` 是没有创建的行，`needs_review` 是已创建但降为待确认的行；两个列表最多各 100 条，超出时 `truncated` 为 `true`。

## 4. 管理端交互

题库列表每行的操作增加「导入」「导出」。

- 导出：下拉里选「JSON」或「CSV」，直接下载。
- 导入：弹窗写明目标题库，拖入或点击选择文件；成功后展示报告（导入、跳过、需修正的数量和明细），点「完成」关闭并刷新题库列表的题目数。失败时显示服务端给出的原因。

## 5. 测试与验收

- 后端：导出只含该题库且分类为路径；CSV 导出再导入后内容一致；JSON 数组与题库文件都能导入；中英文表头与 TSV；去重、无效行、降级待确认的报告；缺表头、空文件、格式不符返回 422；他人题库返回 404。
- 管理端：行内导出会带凭证请求导出接口；导入后展示报告。
- 回归：后端全量、管理端测试与构建、学习端 OpenAPI 类型重新生成、E2E。

## 6. 风险与取舍

- CSV 的选项一格一行，方便在表格软件里编辑；导入时同时接受 JSON 数组和 `|` 分隔，兼容手写文件。
- 去重只看目标题库，导出 A 再导入 B 会得到两份；这是「按题库导入」的可预期行为，报告里写明跳过了多少。
- 分类路径在导入时按需创建，路径拼错会产生新的分类，和命令行导入一致。
